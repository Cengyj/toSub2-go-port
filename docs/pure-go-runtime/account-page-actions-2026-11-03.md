# 账号页全局操作布局调整（2026-11-03）

> 历史记录：2026-11-06 用户要求移除页头回收站及刷新全部账号入口，现已删除相关前端组件、回调和专属样式。侧栏回收站与选中刷新继续保留；当前实现见 `account-header-cleanup-2026-11-06.md`。

## 问题与改动

此前“回收站”单独放在账号管理页标题右侧，“刷新全部账号用量”另占统计标题行的右侧。两个页面级入口分散，标题／统计／操作层级不一致；980px 以下通用页头纵向布局还会让单独的回收站按钮占一行。

本轮只调整这两个入口的呈现与组件职责：

- 页标题右侧统一为账号页面操作组，“刷新全部用量”为主操作，“回收站”为次级描边入口。两个按钮直接可见，不进入“更多”。
- 640px 以下操作组移至说明下方，两个按钮保持同行；刷新占剩余宽度，回收站保留适当宽度。点击区域为 44px，桌面为 40px。
- “账号状态与用量”继续呈现统计和查询进度，移除重复的全量操作按钮；状态异常时保留原只读核实入口。
- 新增 AccountsPageActions 作为无副作用的展示组件，主流程仍负责提交／导航。AccountsOverview 不再接收提交回调；两处共享同一 refreshControl。
- 文案简化为“刷新全部用量”，无障碍名称、范围说明与提示继续明确所有账号。原排队／执行／冷却文案及禁用、查询开关、通知 6 秒收起、所选范围刷新保持。
- 侧栏回收站导航保持；页头回收站只导航，不进行删除或恢复。没有修改后端、依赖或持久化格式。

删除仅限已迁移的统计区按钮和其不再匹配元素的 CSS 规则，没有删除业务功能、测试或恢复代码。
