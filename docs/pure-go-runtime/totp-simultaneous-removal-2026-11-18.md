## 实测支持的建议与仍未覆盖的情况

以下是建议，未改动业务逻辑：

- 日志分别显示“删除回执成功”“登记材料已保存”“激活回执成功”“本地提交成功”和“实际登录验证结果”。当前两边 success 日志并不表示账号只有一个有效因子。
- 对旧 ID 的完整 400 保留拒绝响应，并在明确记录的只读核对后给出“原目标已不存在／出现另一因子／仍不确定”的诊断；不要把通用 400 当作成功，也不要无条件改删新因子。本轮自然行为是停止，若以后增加恢复需单独设计并测试。
