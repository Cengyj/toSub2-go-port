Third-party notices for toSub2 Go runtime, build tools, and browser console
Reviewed against the pinned source and dependency graph on 2026-11-23.

Scope and reproduction
----------------------
This file accompanies the single Go executable as
AUTH_RUNTIME_THIRD_PARTY_NOTICES.txt. It includes the production browser
libraries as well; their original texts are also embedded in
web/dist/THIRD_PARTY_NOTICES.txt and cmd/tosub2/web/dist/THIRD_PARTY_NOTICES.txt.
Go esbuild is a build dependency, not an external JavaScript runtime.

The module versions below come from `go list -m -json all`. Actual package
reachability was checked with CGO_ENABLED=0 and `go list -deps -json
./cmd/tosub2 ./cmd/build-web` for darwin/arm64, darwin/amd64, linux/amd64 and
windows/amd64. `go list -deps ./...` found no additional main-module runtime
or build dependencies. A reachable package is a conservative notice scope;
this inventory does not assert that every function survives linker pruning.
The source files, assembly and embedded data were scanned for attribution
text; matching notices and applicable package-local licenses were reviewed.

Original license wording below is reproduced in full, including upstream
multi-license text; trailing spaces and extra final blank lines are normalized. Copyright notices found in reachable source files and
selected inline license blocks are retained with source paths. SHA-256 values
identify the exact notice file or source excerpt, not the entire component.
Module checksums identify the pinned Go module archives. Re-run this review
when dependencies, build tags, supported platforms or vendored assets change.

Known unresolved upstream notice gap
------------------------------------
github.com/bogdanfinn/fhttp v0.6.9 ships no LICENSE, NOTICE, COPYING or other
license file in its Go module archive. The complete upstream tag tree at
commit a8b14170ef54dc2355c68ec20951a86750fb7732 also has no such file
(https://api.github.com/repos/bogdanfinn/fhttp/git/trees/v0.6.9?recursive=1,
checked 2026-11-23, truncated=false). Both the tag's raw LICENSE URL and
GitHub license endpoint returned HTTP 404. Go-derived source files retain
The Go Authors copyright and a reference to a missing BSD-style LICENSE.
Those source notices and the Go license are preserved below. This is not
proof of a separately stated license grant for every fork-specific addition.
The fork's complete redistribution terms still require upstream clarification
or a separately reviewed replacement before claiming a complete release
license clearance. This notice does not invent that grant or change versions.

The nested engine-probe module and graph-only test/tool dependencies are not
linked by the production executable or this Go frontend builder. Their module
files and upstream source licenses remain relevant when distributing those
separate tools or source trees; this runtime notice does not relabel them as
production dependencies. No legacy cookiejar fork is included: the current
transport uses its own in-memory jar and golang.org/x/net/publicsuffix.
