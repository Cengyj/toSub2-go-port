# 账号三列内容展示优化

日期：2026-11-04。本轮按用户澄清只重组列内内容；表头保留既有文字和样式。继承全部本地成果，不改业务状态判定或真实服务。

## 最终设计

- 操作类型：操作名称与账号保存的授权方式在主行分层展示，名称 13px、授权方式 10px；下一行使用 20px 高状态胶囊。整块摘要为一个日志按钮，避免只能点击小标签。可见文字将“本次已完成／本次操作失败／本次已中断／本次已取消”简化为“已完成／操作失败／已中断／已取消”，将“授权已保存 · 自动回传暂停”简化为“授权已存 · 回传暂停”；完整判定与解释仍在 title 和 aria 中。授权成功但同步失败、同步待核实等复合结果不合并成普通失败。
- 已用比例：两个额度窗口并排，每组分别包含窗口标签、右对齐百分比、细进度条与重置倒计时。共同页脚仅显示一次来源时间、历史/刷新标识与短错误；查询中让位于活动提示的日期仍保留完整提示及原始时间。单窗口保持相同模块宽度，不横向拉长成另一套口径。
- 推理探针：分子 16px、分母 11px，配小型判定胶囊；下一行六段图形只表示正确题数总量，不表示具体题号。无有效当前结果时不画图形、不伪造零分，当前失败/检测中优先，历史结果弱化保留。没有右侧新按钮或箭头，整块仅打开只读详情。
- 三列从相同顶部基线开始，正常内容避免相互争抢视觉权重。复用主题色、细边框和胶囊规范；原有触发资格、日志、详情、主动检测与上传规则保持。

实现：`web/src/components/account-operation.jsx`、`account-usage.jsx/.css`、`account-quality.jsx/.css`、`web/src/styles.css`。有探针时用量基础宽度 216px、探针 138px；为保留独立窗口及右侧按钮触区，表格基础宽度为 1352px，无探针为 1224px。宽屏额外空间继续按权重分配，窄屏局部滚动。

## 回归保护

新增两项 `frontend_indicator_contract_test.go` 回归：有效六题结果的聚合图形、空数据/权限状态不伪造用量。扩充操作摘要、探针和用量既有测试，保留唯一原生按钮、无嵌套交互、只读回调、历史/失败优先级、零值和未知的不同含义。

视觉结构断言随展示变化更新：操作断言精确检查状态胶囊短文案，同时继续检查完整 title/aria；HTTP 与额度用尽由“附属最后一个窗口的重置行”改为共享页脚一次展示。确认可见满额窗口时通过数据索引与完整提示保留对应关系；只有全局限制标志、窗口数值不足以归因时，不再把限制归给某个未知窗口。没有改变上游限制判定、窗口排序、原始比例或重置时间。
