## 本次观察与用户选择

原会话只读核实于北京时间 2026-11-06 11:17:55 返回 old_factor_enabled：该次读取看到唯一有效因子 ID 与历史旧因子一致。它未验证保存的旧密钥，也未证明历史移除请求从未发送。当前账号没有已保存的 OAuth 授权文件，仍有原登录 checkpoint 与私有恢复 journal。

用户明确选择“暂不再次发送移除请求，保留现有 2FA”。本轮不新增或执行重置、不重新登录、不请求邮箱验证码、不解除隔离、不修改凭据或 Cookie。

## 确认的展示缺口

协议取得具体结果并写入私有 journal，但 jobs 的 inspect 分支跳过整个结果，随后通用完成提示覆盖了具体观察。公开 API 和账号行只显示“已完成、未解除隔离”，原重置错误仍为旧的通用错误，未给用户展示已经核实的远端状态。

## 本轮修复

- 独立保存观察枚举、观察时间和服务端固定中文说明。仅接受五种已知枚举，严格解析时间，不发布私有错误原文、因子 ID 或任何密钥/令牌。
- 本轮成功提示使用本轮有效观察；后来失败保留上一条成功观察并明确标为历史，不用旧结果冒充本次成功。
- 旧记录可从完整、账号绑定且私有的 journal 回填展示字段，保留检查时间；回填不联网、不改变重置状态/密钥/保护标志。
- 协议检查消息和检查错误使用独立字段，检查成功或失败均不再覆盖原重置错误；公开错误保留安全原因并避免泄漏本地路径及认证资料。
- 账号行明确展示核实结果和时间；保护提示不把“仍受本地限制”写成“官方已经停用旧密钥”。

## 未解决边界

本轮只修正信息展示，不把只读成功等同于恢复。项目目前没有已确认可在该 ChatGPT 原会话中独立验证旧 TOTP seed 与 factor 对应的接口；登录挑战接口依赖认证挑战上下文，不能假定可在此会话直接使用。因而在不再次移除、不重新登录且缺少充分验证证据的限制下，尚不能宣称已验证旧密钥并安全解除全部隔离。

历史 unknown 证据继续保留。普通登录、重置和资料导出等原受限功能不会因这次展示修复被偷偷放行。
