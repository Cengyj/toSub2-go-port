## 已定位的故障边界

捕获 JavaScript 异常。`frame=false child=false` 等标志表示对应事件未被观察到。
`requests=2 last_http=200` 只表示运行时完成过两个请求，最后响应为 200，
不能作为网站验证或 OAuth 成功证据。

## 本轮优化范围

修正首次授权选择上传时遗漏上传状态的界面展示；授权尚未保存时，上传跳过
应明确表示“授权未完成，未执行上传”，不能建议上传一份尚未生成的新授权。
网站验证脚本异常提供中文摘要，原技术错误保留在详情/原始日志中。

新增诊断仅用于后续新操作中的异常位置定位，不补写历史日志，不改变脚本执行、
网站验证成功条件、账号凭据或自动重试策略。

运行时错误可附加 `location: {line, column}`，两项都必须是 1 至 1,000,000
之间的整数。位置来自 Sobek 原生 `Exception.Stack()`，不读取 JavaScript 的
`.stack` 属性，不传文件名、函数名或异常正文。工作进程协议和接收端都校验
坐标；缺少位置的旧消息继续可用，非法位置拒绝作为有效诊断。
公共错误保留 `code + phase`，仅在有合法位置时追加 `[line=… column=…]`。

坐标表示引擎首个具有合法位置的栈帧，可能是 Error 创建位置或 source map
映射位置，不能单凭数字把它称为真正的抛错原句。下一次错误即使仍无坐标，
原有失败与上传保护也继续生效。

该账号已经重新授权成功。具体语句仍需新的当次诊断与可脱敏复现才能确认。
