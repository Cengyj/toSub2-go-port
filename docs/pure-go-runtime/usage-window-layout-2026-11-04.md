## 实现

- 每个窗口固定两行：首行窗口名称与右对齐的真实百分比；次行进度轨与右对齐的中文重置说明。取消脱离窗口的共享重置汇总和重复窗口缩写。
- 重置说明使用原倒计时取整语义，改为直接可读的“5天2小时后重置”；到点显示“重置待确认”，未知显示“重置未知”，不自动补满额度。
- 重置区域固定 104px，同宽单元格的轨道等长。192px 内容宽度下保留 80px 轨道；原始比例继续独立显示，没有舍入或合并。
- 底部只有一条记录／历史／当前状态／错误行，“历史”用轻量小标记。额外窗口数量放在最后可见窗口名称旁，不挤占异常提示。密集状态仍优先保留当前错误等提示，完整观察时间可从提示和详情查看。
- 单窗口不预留虚假的第二窗口空间；双窗口按真实内容增加高度。各窗口36px，底部状态18px，排队、执行、终态不会增加结构行。
- 保留一个只读详情按钮、透明悬浮背景与键盘焦点。探针、账号操作、后端查询和业务判定不变。

生产文件：`web/src/components/account-usage.jsx`、`account-usage.css`。清理的是被替代的共享重置汇总及其专用 CSS；没有删除业务、平台代码或测试。新增合成 `weekly / weekly-error` fixture 复现本轮单周历史场景，不读取真实账号。
