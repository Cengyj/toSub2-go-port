# 账号表格三列紧凑化修订

> 本记录保留本轮紧凑布局的历史依据；当前辅助标签与状态的视觉已由同日[胶囊精修](account-table-pills-2026-11-04.md)继承。请以新记录的截图、构建摘要和部署状态为准。

日期：2026-11-04。用户反馈上一版仍不精致、小巧，且推理探针右侧增加了重复按钮。本轮据此继续实际修改，而非仅改变字号。开始时沿用全部本地未提交成果；上一版尚未部署，维护流程当时只进行只读检查，没有暂停后台或改动 4401。

## 证据与设计调整

原界面每个用量窗口占用标题、进度条与重置三行，双窗口组件实际高 137px；探针同时展示结果、详情文字、独立发起和通过说明。1440px 下时间记录还因列宽不足将日期时间断成两行，使无用量数据的普通账号行也高达 141px。

本轮采用以下结构：

- 操作类型：名称与弱化授权方式相邻；状态作为无底色的次要文字与图标，删除大面积彩色底色，保留失败、待核实、部分完成等完整状态。状态点击继续打开原日志。
- 已用比例：每窗口为“短窗口名 + 细进度条 + 右对齐百分比”，下方一行放重置与短错误。主比例为 13.5px 等宽数字，常见 61.25% 实测完整显示；不把不同窗口合并。
- 推理探针：当前有效分数与小型通过判定同行显示。整块仅一个只读详情按钮，移除右侧“发起”和常驻“详情”文字；历史结果或当前失败等按需第二行显示。
- 主动检测保留在详情、账号更多与工具栏；没有删除功能，也没有将查看结果改成隐式检测。详情内资格、冷却、BPS 限制、取消和消耗提示不变。
- 查询活动移到固定页脚槽，保持正常、排队、运行和失败时的行高。来源观察完整时间仍在提示与无障碍文本中，历史标记保持可见。
- 重新分配时间记录列宽，保留完整秒数但避免断行；表格行内上下留白收敛至 10px。基础列宽合计为有探针 1308px、无探针 1188px，宽屏按权重填满可用区域。

实现主要位于 `web/src/components/account-operation.jsx`、`account-usage.jsx/.css`、`account-quality.jsx/.css`、`accounts.jsx` 与 `web/src/styles.css`。没有修改业务状态判定、授权文件、查询调度、评分、上传门禁、恢复流程或数据格式。

## 精简依据

- 删除探针摘要的 `onCheck/canCheck` 参数与单元格发起按钮：该区域只负责查看结果，发起行为已有详情、更多和工具栏入口；新的只读测试验证点击结果不能提交请求。
- 删除常驻“详情”、重复当前观察前缀及状态大面积背景：详情可发现性由小箭头、原生按钮和聚焦反馈保留；完整说明进入提示与详情。
- 历史观察只显示月日，完整来源时间与原始 `dateTime` 保留。对应测试改为分别验证历史短日期、当前月日时分、完整提示及正确来源，不放宽时间或历史语义。
- 未删除业务测试、平台实现、恢复分支、授权资料或许可证；构建只替换对应的哈希前端资源。
