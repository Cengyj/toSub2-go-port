## 三条观察路径与边界

三条路径均为 B 退出前状态的观察复制件，没有额外登录：原 token 路径固定使用原 token 与退出前请求上下文；固定 Cookie 路径每次由同一 Cookie 快照请求 session，再使用返回 token 查询业务；轮换路径接受 Set-Cookie，再以 session 返回 token 查询业务。三个 HTTP 客户端、Jar 相互独立，基线完成后重置为相同退出前快照。

固定路径仅在观察复制件将本地 Expires 清零，使每次发送相同 Cookie 值；轮换路径保留真实 Expires。#37 记录快照 30 个 Cookie，24 个有 expires、6 个会话 Cookie，快照时没有已过期 Cookie。公开只记录 expiry 日期/数量与指纹。固定路径的请求 Cookie 指纹始终为 `4117fc4dc5009cbf`；轮换路径的请求指纹确实变化。

观察器只允许 GET `/api/auth/session` 和 GET `/backend-api/accounts/mfa_info`，不自动登录、OAuth 刷新、挑战恢复或跟随跳转。S5 驱动拒绝 reset/prepare 命令及 disable/enroll/activate 传输。日志中 2FA 修改为 0 次、logout_all 恰好 1 次。认证登录的 POST 发生于观察前，不属于失效探针。
