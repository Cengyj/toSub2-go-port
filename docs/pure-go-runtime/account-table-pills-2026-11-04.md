## 信息层级与实现

- **操作类型**：13px 操作名称为主；授权方式使用 16px 高中性胶囊。操作状态使用 18px 高胶囊，保留完整的授权、同步、失败、待核实和部分完成含义。删除状态旁独立箭头；点击状态仍展开原日志。
- **已用比例**：13.5px 原始百分比与 3px 细进度条保持清晰。5h / 7d 使用 16px 中性微胶囊，HTTP 错误与用尽短提示使用 14px 微胶囊。窗口分开显示，百分比、历史时间和重置说明不重复包框。
- **推理探针**：15px 深色比分为主，旁边以 14px 胶囊表示通过或低于阈值；未检测、排队、检测中、失败、未知和不支持使用 18px 状态胶囊。小箭头融入胶囊内部，不增加右侧按钮。
- **统一样式**：新增 `web/src/components/account-indicators.css`，三列共用圆角、轻边框、淡色背景、图标比例和语义色；使用现有主题变量，不新增依赖或主题体系。胶囊只负责视觉，原生按钮保留不少于 28px 的点击高度、悬浮及键盘焦点反馈。
- **状态与动作**：探针单元格仍只有一个只读详情入口；显式检测保留在详情、更多和工具栏。历史结果不覆盖当前失败或活动状态；用量未知不显示为零，保存未确认、历史来源、HTTP 错误继续可见。

主要实现：`account-operation.jsx`、`account-usage.jsx/.css`、`account-quality.jsx/.css` 与 `web/src/styles.css`。没有改动授权身份、查询调度、探针评分、上传门禁、恢复流程、数据格式或服务端设置。表格宽度沿用上一版有探针 1308px、无探针 1188px 的基础分配，宽屏继续按比例使用空间。
